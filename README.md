# YouTube Cinema — Redesign

A content-first, cinematic YouTube web experience built with quiet luxury aesthetics, fluid responsive layouts, a dynamic 3D discovery orbit, and an immersive, glassmorphism sign-in experience.

## ✨ Highlights

- **Aesthetic Video Canvas**: Hazy, desaturated full-bleed background video with soft edge vignettes and zero overlap.
- **Atmospheric Floating Worlds**: Dual parallel tracks sliding in opposite directions on scroll with dynamic card crossfades.
- **3D Discovery Vault**: Hardware-accelerated CSS 3D orbit engine with trigonometric projection math (`Math.cos`/`Math.sin`) dynamically scaling across viewports.
- **Dynamic Bento Categories Showcase**: 12-column hierarchical grid with bespoke ambient hover glows and live equalizer soundwaves.
- **Cinematic Sign In Modal**: Frosted glassmorphism panel (`backdrop-filter: blur(36px)`), Google authentication option, and password visibility toggle.
- **Full Responsive Design**: Seamless optimization across mobile phones, tablets, laptops, and ultra-wide displays.
- **Decisions & Architecture**: See [`DECISIONS.md`](./DECISIONS.md) for architectural trade-offs, ingestion strategies, and technical decisions.
